# **Why Are We Here?**

When I started using vibe coding, I wanted to create a game. I come from an art background and have almost no coding experience, so vibe coding sounded like a tool that could help me complete a game the fastest. But soon, I found that it wasn't as good as I had imagined, especially when I had no knowledge of programming at all.From my perspective, although existing AI tools are increasingly capable of generating working code, they cannot always make the choices and judgments that I need. For me, this ability to make judgments is crucial because it is what allows a work to develop in the direction I actually intend. AI can provide solutions, but it does not necessarily know which solution is right for my particular work.

I experienced this when I tried to make a simple game in Unity with ChatGPT. I wanted the character to move from one grid cell to another, like a character in RPG Maker. ChatGPT could generate code that made the character move, and the code could run. In that sense, it was successful. But it was not what I wanted. The character could move freely instead of being constrained by the grid. The difference seems small, but for me it changed the entire feeling of the game.

This experience made me realise that “working” and “right” are not the same thing. This also made me think about Don Ihde’s idea that technology is not simply a neutral tool between a person and their goal. The tools we use can shape how we perceive what is possible and how we approach making something. I think programming works in the same way. AI could solve the technical problem of making a character move, but it could not automatically know why I wanted grid-based movement. This is why I have started to think of programming as a language. AI can act like a translator between what I imagine and what a computer can execute. But translation is never exactly the same as meaning. A sentence can be grammatically correct and still express the wrong idea. In the same way, code can be functional and still be artistically wrong.

There is also something strangely romantic about learning a language myself. If I always depend on a translator, I can communicate, but I never have the same relationship with the language. I want to understand enough code that when AI gives me something, I can read it rather than simply accept it. I want to be able to say, “This works, but this is not what I mean.”

Sometimes I imagine an extreme situation in which the technologies I depend on simply stop working. It is probably unrealistic, but the thought is useful to me. If all the external tools disappeared, what would remain? I would still have my knowledge, my judgement, and my ability to think. AI is an external system that can assist me, but I do not want my ability to create to exist only through that system.

I am here because I want to understand the material well enough to make my own decisions. If AI is going to write the code, I want to know enough about code to argue with it.
