# WHY-WE-ARE-HERE



From my personal perspective, I believe that although the existing tools have the ability to generate code, they are unable to make choices and judgments. For me, this ability to make judgments is crucial as it is the core capability that ensures the work always progresses in the right direction.



I started learning programming with the intention of creating games. During my undergraduate studies, I majored in fine art and had almost no programming foundation. I once tried to write code using ChatGPT and create simple games in Unity. However, after receiving the code, I was unable to truly control it. The AI couldn't fully understand my thoughts. For example, I wanted the game character to move along the grid cells one by one like in RPG Maker, but the code generated by the AI would make the character move freely outside the grid constraints, which was not the effect I wanted.



In my opinion, programming is itself a language. For those who are not familiar with code, the AI is like a translator, but the results given by the translator are not always accurately and precisely in line with the original meaning. To truly understand a language, one must learn it personally. This learning process is very romantic for me.



Even though AI can now complete a lot of work, I still have many doubts about it in my heart. Perhaps influenced by literary works, I always imagine that this new technology might collapse. This idea sounds unfounded and almost absurd. But I always think that if all civilizations collapse, humans can rely only on their own minds, rooted in their own knowledge. AI is ultimately just an external thing. It can assist me, but it cannot replace me.
